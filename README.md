# Alokananda (অলকানন্দা) - E-commerce Store 🛍️

A fully functional, customized e-commerce website built for a local business in Bangladesh. This project leverages WordPress and WooCommerce to provide a seamless shopping experience for customers.

## 🌐 Live Demo
[Click here to visit the live website](http://alkananda.rf.gd/)

## ✨ Key Features
* **Custom Homepage:** Designed with a clean, user-friendly interface to showcase products.
* **WooCommerce Integration:** Complete shop setup including product catalog, cart, checkout, and order management.
* **Localized Payment Setup:** Configured specifically for the Bangladeshi market with "Cash on Delivery" (COD).
* **Advance Payment Instructions:** Custom checkout messages requiring advance delivery charges via bKash/Nagad for order confirmation.
* **Dynamic Shipping Rates:** Configured conditional shipping rates for "Inside Dhaka" and "Outside Dhaka".
* **Custom Branding:** Integrated custom logo and brand identity for "Alokananda".
* **Optimized Checkout:** Tax-inclusive pricing setup to prevent checkout abandonment.

## 🚀 How to Run Locally
If you want to test this project on your local machine:
1. Setup a local server environment (e.g., XAMPP, WAMP, or LocalWP).
2. Install a fresh copy of WordPress.
3. Clone this repository's `wp-content` folder into your local WordPress installation.
4. Activate the theme and plugins from the WordPress dashboard.
